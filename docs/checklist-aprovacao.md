# Checklist de aprovação — prévia do site

Documento para a Clínica Neiva Fernandes revisar a prévia antes da publicação.
Cada item marcado precisa de uma resposta ou de um material para que o site
saia do ar como demonstração e vá para o domínio definitivo.

## 1. Como ler esta prévia

- A faixa **"Prévia"** no topo indica que o site é uma demonstração.
- Textos, depoimentos, formação, e-mail e CNPJ são **ilustrativos**.
- Todas as fotos são de banco de imagens (Pexels) e serão trocadas.
- O site está com `noindex` — não aparece no Google enquanto for prévia.
- O formulário **não envia dados para nenhum servidor**: ele apenas monta a
  mensagem e abre o WhatsApp do visitante. Não há armazenamento no site.

## 5. Depoimentos

Os seis depoimentos da prévia são **fictícios** e usam apenas iniciais. Para
publicar:

- [ ] Enviar depoimentos reais de pacientes, com autorização expressa por

- [ ] Ou autorizar a remoção da seção de depoimentos.
- [ ] Definir se os depoimentos podem citar resultado clínico (por padrão, não).

- Suíte de testes automatizados de regressão, acessibilidade e layout.
